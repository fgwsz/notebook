## 🎯 最终目标
在 Ubuntu (amd64) 上安装富士施乐 DocuCentre S2110 打印机的毕昇驱动，并找到 PPD 文件用于添加打印机。

## 📦 第一步：安装必要依赖

### 1. 添加 i386 架构支持（若未添加）
```bash
sudo dpkg --add-architecture i386
sudo apt update
```

### 2. 安装 `deepin-elf-verify`
从 Deepin 源下载并安装：
```bash
wget https://mirrors.cqupt.edu.cn/deepin/pool/main/d/deepin-elf-verify/deepin-elf-verify_1.2.0.6-1_amd64.deb
sudo dpkg -i deepin-elf-verify_1.2.0.6-1_amd64.deb
```

### 3. 通过 i-m.dev 源安装 `deepin-wine-runtime`
```bash
wget -O- https://deepin-wine.i-m.dev/setup.sh | sh

sudo apt install deepin-wine-runtime
```

## 🧩 第四步：通过 CUPS 添加打印机

1. 浏览器打开：`http://localhost:631`
2. 点击 **Administration** → **Add Printer**
3. 选择检测到的 USB 打印机（名称含 `USB` 和 `S2110`）
4. 在 **Make** 处选择 **Provide PPD file**
5. 浏览并选择：`/usr/share/ppd/printer-driver-deepinwine/Fuji Xerox-FX DocuCentre S2110.ppd`
6. 完成添加，打印测试页。

## 💡 注意事项
- 首次打印时 Wine 环境可能需要初始化，会稍慢，请耐心等待。
- 如果打印无反应，查看 CUPS 错误日志：`sudo tail -f /var/log/cups/error_log`
- 若系统重启后打印机消失，检查 CUPS 服务是否自启：`sudo systemctl enable cups`

按照以上步骤，你可以干净、快速地完成驱动安装，无需再经历之前那些错误的依赖尝试。

选择通信协议取决于你的打印机是如何连接到电脑的。根据你的情况，推荐如下：

### 🔌 如果是USB直连（推荐）
**首选 `usb://` 协议**。这是最直接、最稳定的方式，CUPS 会自动检测并选用，你通常无需手动选择。在 CUPS 添加界面，直接选中带有 `usb://` 开头的设备即可。

### 🌐 如果是网络连接（局域网）
按以下优先级选择：

1. **首选 `ipp://` (Internet Printing Protocol)**：这是现代网络打印的标准协议，也是 CUPS 的原生协议，功能最全，兼容性最好。端口通常是 **631**。URI 格式类似：`ipp://打印机IP/ipp/print` 或 `ipp://打印机IP:631/printers/打印机名称`。

2. **次选 `socket://` (AppSocket/HP JetDirect)**：如果 IPP 无法连接，这是最通用的替代方案，直接将打印数据发送到 TCP 端口。端口通常是 **9100**。URI 格式：`socket://打印机IP:9100`。

3. **最后尝试 `lpd://` (Line Printer Daemon)**：一种较老的 Unix 打印协议，端口 **515**。如果前两者都不行再考虑。URI 格式：`lpd://打印机IP/队列名`，队列名常见为 `LPT1`、`lp1` 等。

### 💡 给你的 S2110 的具体建议
鉴于你已经成功安装了毕昇驱动（含 Wine 环境），**USB 直连是最省心的选择**。如果必须走网络，优先在 CUPS 中添加 `ipp://` 协议的打印机。

你可以先在终端运行 `lpinfo -v | grep ":/"` 来查看系统当前检测到的可用设备 URI，根据输出结果再做选择会更准确。
