注意:Ubuntu系统的`super`键的位置和为Windows系统中的`windows`键一致
`ctrl alt t` 打开终端
`super up` 最大化窗口
`super Fn` 切换窗口
    进入待选界面
    使用方向键移动待选窗口框

    按住`alt`,然后按一次`tab`进入待选界面(显示窗口缩略图和窗口图标)

    使用方向键移动待选窗口框到想要跳转的窗口
    使用`tab`键移动待选窗口框到下一个窗口

    按住`super`,然后按一次`tab`进入待选界面(只显示窗口图标)
    之后可以松开`tab`键
    使用方向键移动待选窗口框到想要跳转的窗口
    使用`tab`键移动待选窗口框到下一个窗口
    松开`super`跳转到待选窗口框里的窗口
`alt Esc` 切换窗口(直接切换,不显示待选窗口框)
`alt F4` 关闭窗口
`super d` 显示桌面/恢复原先的显示窗口
`super l` 锁屏
`super ↑` 窗口最大化
`super ↓` 窗口居中显示

[command 1] | [command 2]
    管道符号的作用:
        将[command 1]指令的执行结果作为[command 2]指令的(最后一个)输入参数
        并执行[command 2]
    管道符号可以连接两个或多个指令,例如:
        echo "hello" | grep "hel" | cat > 0.txt
        它的工作原理相当于如下的指令组合:
        cat $(grep "hello" $(echo "hello")) > 0.txt

touch [file path]
    新建一个路径为[file path]的文本文件

mkdir [dir path]
    新建一个路径为[dir path]的文件夹

    强制删除路径[path]的文件/文件夹

        .  当前目录
        ~  用户根目录

            ```bash
            mv -v oldname.txt newname.txt

            ```

tar -czvf [.tar.gz file path] [input path]...
    压缩文件为.tar.gz

    压缩文件为.7z

    [input path]指的是要被压缩的文件路径,可以是单个文件,也可以是文件夹

[command] &
通过在命令后添加`&`符号,将命令[command]放在后台运行,
不会避免阻塞当前的指令执行进程.
如果`[command] &`放到脚本中,
无论执行结果如何,都会继续执行后续的bash指令.
而且`[command] &`可以让[command]在自己的子进程中运行
而不会作为bash解释器的子进程.

curl [url]
    安装`sudo apt install curl`
    功能一:下载[url]指定的文件到本地
        `-o [path]`                 指定下载路径(支持绝对路径和相对路径)
        `-C -`                      使用断点续传功能
        `--retry [number]`          自定义断点续传重试的次数
            只写`--retry`不写[number],代表无限次数
        `--retry-delay [seconds]`   自定义每次断点续传重试之前延时的秒数
        `-L`                        支持重定向的链接
        `--http1.1`                 使用http1.1进行下载,默认使用http2.0
        指令的返回值
            成功时返回0
            失败时返回错误码
    功能二:获取[url]指定的文件的大小
    ```bash
    #文件的网址
    url="www.xxx.com/yyy.txt"
    #获取文件大小
    remote_size=$(curl -sI "$url" | grep -i Content-Length | awk '{print $2}' | tr -d '\r')
    remote_size=${remote_size% } #去除尾部的空白字符
    #判断文件是否存在
    if [ -z "$remote_size" ]; then #-z 表示判断是否为空字符串
        echo "Unable to retrieve the size of the remote file."
    fi
    ```

aria2c [磁力链接]
    用来下载磁力链接
    安装`sudo apt install aria2`
    `-d [path]`     下载文件的存储目录
    `-o [filename]` 下载文件的名称
        它总是相对于在-d选项中给出的目录
        当使用-Z选项时,此选项将被忽略
    aria2c的配置文件路径在`~/.config/aria2/`文件路径下,
    如果没有这个文件夹的话可以自行创建,并创建如下路径:
    ~/.config/aria2
        ├── aria2.conf
        ├── aria2.log
        └── aria2.session
    `aria2.conf`是配置文件,
    `aria2.log`是日志文件,
    `aria2.session`是下载器进度保存文件,
    `aria2`启动的过程中会从这个文件夹读取下载参数和配置.
    注意:
        在`aria2.conf`这个配置文件中无法将`~`这个用户目录文件夹的通配符,
        识别成正确的用户目录文件全路径,
        请自行更改为实际的用户目录文件全路径
    下面给出一个`aria2.conf`配置文件的实例作为参考:
    ```txt
    # /home/fgwsz/.config/aria2/aria2.conf
    # 日志文件路径
    log=/home/fgwsz/.config/aria2/aria2.log
    # 下载目录
    dir=/home/fgwsz/Downloads
    # 输入文件路径(记录下载历史)
    input-file=/home/fgwsz/.config/aria2/aria2.session
    # 输出文件路径(保存下载历史)
    save-session=/home/fgwsz/.config/aria2/aria2.session
    # 启用 DHT (IPv4)
    enable-dht=true
    # DHT 文件路径
    dht-file-path=/home/fgwsz/.config/aria2/dht.dat
    # DHT 监听端口范围
    listen-port=6881-6999
    dht-listen-port=6881-6999
    # 启用本地节点发现 (LPD)
    bt-enable-lpd=true
    # 启用节点交换扩展
    enable-peer-exchange=true
    # 断点续传
    continue=true
    # 文件预分配方式
    file-allocation=falloc
    # 最大并发下载任务数
    max-concurrent-downloads=5
    # 同一服务器最大连接数
    max-connection-per-server=10
    # 整体下载速度限制(单位:字节/s),0 表示无限制
    max-overall-download-limit=0
    # 单个任务下载速度限制(单位:字节/s),0 表示无限制
    max-download-limit=0
    # 整体上传速度限制(单位:字节/s),0 表示无限制
    max-overall-upload-limit=0
    # 单个任务上传速度限制(单位:字节/s),0 表示无限制
    max-upload-limit=0
    ```
    其中`/home/fgwsz`是我的用户目录的全路径

lsblk
    用于查看硬件设备的盘符和存储空间的信息
    一个奇怪的用处:
        用来查看U盘的盘符是多少,在插入U盘之前使用该命令来查看,
        插入U盘之后再次使用该命令即可得知U盘的盘符,一般都是sdb[number]

rsync -avzh --delete [source path] [target path]
    目录内容同步
    让[target path]目录的内容变成和[source path]目录的内容完全相同
    [path]的目录不局限于本地目录,也可以是远程服务器的目录.
    安装 rsync
        ```bash
        sudo apt-get install rsync
        ```
    下面是参数解释:
    -a:归档模式,保留文件属性,并递归同步.
    -v:显示详细过程.
    -z:传输时压缩,节省带宽.
    -h:以易读的格式输出信息.
    --delete:最关键选项.删除目标目录中存在但源目录中不存在的文件.这正是实现"完全一致"所必需的.
     -n (--dry-run):进行试运行但不会实际执行
    一个具体的案例:
        ```bash
        #让远程服务器的/path/to/remote/target内容与本地的/path/to/local/source完全相同
        rsync -avzh --delete /path/to/local/source/ user@remote-server.com:/path/to/remote/target/
        ```
    如果你是想把远程目录同步到本地,只需调换源和目标:
        ```bash
        #让本地目录/path/to/local/target内容与远程服务器/path/to/remote/source完全相同
        rsync -avzh --delete user@remote-server.com:/path/to/remote/source/ /path/to/local/target/
        ```
        警告: --delete 参数会删除文件,所以使用前务必确认命令的源和目标路径是否正确!
        建议先使用 -n (--dry-run) 参数进行试运行,看会有什么变化而不实际执行.

sed [-i] "{expr1}; {expr2}; ... {exprn}" [file-path]
    sed 是一个强大的文本处理工具,我主要用它进行文件的文本内容替换.
    -i
        表示原位置修改,注意:不可用于控制台管道符号传来的缓冲区字符串.
        不写-i表示不修改原文件内容.

    -i.bak
        表示原位置修改,并备份(将修改前的文件另存为[file-path].bak)

    -e "expr"
        可以使用-e 标识符号来代替`;`分隔多个语句.
        "expr1; expr2; expr3" 等价于 -e "expr1" -e "expr2" -e "expr3"

    -z
        sed默认按行处理,每读入一行就截掉行尾的换行符(`\n`),
        所以`\n`根本不会出现在模式空间中,
        因此普通模式下"s/\n//g" 永远匹配不到`\n`,
        无法使用"s/\n//g"删除字符串中的换行.

        `-z`选项将整个输入作为一个整体字符串读入,
        此时换行符退化为普通字符,可以被正则匹配和替换.
        因此`-z`模式可以使用"s/\n//g"删除输入中的换行.

        `-z`模式可以和`-i`模式配合,组合参数形式为`-zi`

        注意:普通模式和`-z`模式都可以使用`s/\r//g`删除回车`\r`.

    sed 的输出为"expr"序列处理后的字符串,可以与>/>>/|配合
        写入/追加写入/作为参数传递给下一个命令

    -n
        关闭sed的默认输出

    expr是什么呢?
        expr有很多类型,我常用的是全局替换语句,
        它的写法和vim的`:%s`替换表达式很类似.

        例如:
            #将全部的`hello.world\n`替换为`666\r`
            vim全局替换命令是这样的:
                `:%s/hello\.world\n/666\r/g`
            sed的expr是这样的:
                "s/hello\.world\n/666\r/g"

        新的技巧: -n + p
            上述替换expr中g指的是global行内的全部
            可以附加p,p是print,意思是发生替换的时候,打印发生替换的那一行.
            但是这好像没有什么用,因为sed默认会输出处理后的全部文本内容.
            可以使用 -n 来关闭sed的默认输出.
            由此可以使用 -n 配合 g和p
            也就是:
                sed -n "s/xxxx/yyyy/gp" file-path

    用法举例:
        sed -n "s/hello/world/g; s/abc\.6/de/gp" file.txt > file2.txt
        sed -i "s/hello/world/g; s/abc\.6/de/g" file.txt
        sed "s/hello/world/g; s/abc\.6/de/g" file.txt | rg world

binwalk [binary file path]
    Binwalk 是一个专为固件分析设计的逆向工具,但在 CTF 隐写题里,
    它成了"照妖镜"--专门用来识别和提取文件中夹带的"私货".

    强项:处理"文件拼接"
    (一张图片尾部粘了另一张图片或 ZIP 包)|识别嵌入的压缩包.

    安装:sudo apt install binwalk

    binwalk [binary file path]
        扫描(看结构):`binwalk 文件名`
          只列出分析结果,不做任何修改.你之前得到的偏移地址列表就是靠这个.

    -e
        这是 `binwalk` 的常规提取模式.
        它会扫描文件里所有的"文件头特征"
        (比如 JPEG 开头是 `FF D8`,PNG 开头是 `89 50 4E 47`),
        只要识别出是它认识的文件类型,就自动帮你抠出来.

        但有个缺陷:如果某个数据块的特征没那么标准,
        或者藏的是纯文本|自定义数据,`-e` 可能会选择忽略它.

        但是我实际测试下来并不会提取文件,需要添加--dd=".*"才可以提取.

    --dd=".*"
        这是强行补刀的参数.
        - `--dd` 的意思是"用类似 Linux `dd` 命令的方式,
        把某一段二进制数据原封不动地抠出来存成文件".

        暴力拆分(深水区):
            `binwalk -e --dd=".*" 文件名`
        不分青红皂白,把扫描到的每一个数据块都强行切成独立文件,
        自动识别并提取所有能识别的文件,解压到 `_文件名.extracted` 文件夹.
        用于对抗文件头被篡改的情况.

        `".*"` 是正则表达式,意思是 "匹配所有内容"(什么都别放过).
        组合起来的效果就是:
            `binwalk` 扫描到多少个数据块(无论它认识不认识),
            就强行把每一个数据块都单独保存成一个文件.

    总结:
        - 只有 `-e`:相当于"警察只抓有案底的通缉犯"(只提取 JPEG|ZIP 等常见格式).
        - 加上 `--dd=".*"`:相当于"宁可错杀一千,绝不放过一个",
        把扫描到的所有碎片(包括疑似文件的头|中间的数据|尾巴)
            全部切成小块扔进文件夹.

    `[按住]shift [按多次]↑/↓/←/→` 选中多个文件/目录
        松开shift,按↑/↓/←/→进行移动就可以取消多选
    `enter` 打开待选框中的文件/目录
        目录:进入该目录
        文件:用默认应用程序打开文件
            可执行程序:运行可执行程序
    `ctrl c` 复制
    `ctrl v` 粘贴
    `ctrl x` 剪切
    `ctrl i` 打开文件右键属性菜单界面
    `delete` 删除
    `ctrl a` 全选
    `ctrl z` 撤销
    `ctrl Z` 取消撤销
    `F2` 重命名
    `ctrl l` 进入地址编辑栏
    `ctrl n` 打开一个新的和当前文件路径一致的文件浏览器窗口
    `shift ctrl n` 新建目录
    按住`ctrl`鼠标滚轮上滑 放大图标显示百分比
    按住`ctrl`鼠标滚轮下滑 缩小图标显示百分比

linux microsoft-edge
    `ctrl n`         打开一个新的edge窗口,并显示`new tab`页
    `ctrl t`         打开一个新的标签页,并进入地址输入栏
    `ctrl d`         收藏当前标签页
    `ctrl w`         关闭当前标签页
    `ctrl tab`       切换到下一个标签页
    `ctrl shift tab` 切换到上一个标签页
    `ctrl j`         打开下载标签栏小窗口,之后可以使用`tab`键来选择选项按钮,`enter`来点击按钮,`esc`键退出小窗口
    `ctrl p`         打印当前网页
    `ctrl f`         搜索当前标签页内容
                         弹出搜索框,键入要搜索的字符串后
                         匹配内容会实时高亮显示
                         并将网页位置自动跳转到第一个匹配位置
                        `return`(回车键`enter`) 跳转到下一个匹配
                        `shift return` 跳转到下一个匹配
                        `esc` 退出搜索框
    `ctrl o`         弹出资源管理器子窗口
                        选中文件并点击`open`按钮后,在当前标签页加载选中的文件
                        `esc` 退出资源管理器子窗口
    `ctrl s`         保存当前标签页(弹出资源管理器子窗口选择保存路径和文件名)
    `ctrl shift s`   为当前标签页截图
                        弹出功能选择菜单:(`tab`键可切换待选项,`enter`键确定)
                            1.捕获用户所选中区域
                                选中之后,需要用鼠标选择要截图的矩形区域
                            2.捕获标签页全部内容形成滚动长图
                        `esc` 退出
    `alt d`          进入标签页地址栏
    `alt ←`          后退
    `alt →`          前进
    `alt p`          固定/取消固定标签页
    `space`          网页视图显示范围的下一页
    `shift space`    网页视图显示范围的上一页
    `↑`              网页视图显示范围上移一段距离(不平滑移动)
    `↓`              网页视图显示范围下移一段距离(不平滑移动)
    `←`              网页视图显示范围左移一段距离(不平滑移动)
    `→`              网页视图显示范围右移一段距离(不平滑移动)
    按住`ctrl`鼠标滚轮上滑 放大网页页面显示百分比
    按住`ctrl`鼠标滚轮下滑 缩小网页页面显示百分比

linux Document Viewer
