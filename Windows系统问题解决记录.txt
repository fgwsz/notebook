2026.3.4 在往U盘复制文件的时候显示0x800700EA错误
解决方式:
    因为我的windows操作系统开启了unicode支持,
    U盘可能使用的是GBK编码,因为往U盘复制文件的时候产生了这个错误.
    解决方式很简单:把要复制的文件的文件名使用标准ascii码重命名一下,
    就会发现这一正常复制了.
    如果是多个文件,可以存放在一个文件夹里面压缩,使用标准ascii码为压缩包重命名,
    问题即可解决.
2026.3.30 开机后黑屏只有鼠标,使用快捷键(ctrl+alt+del/esc)无法调出任务管理器
    在使用alt+tab快捷键切换的时候可以看到任务管理器后台进程缩略图
    但是无法切换进入
解决方式:
    强制长按电源键3次关机开机,会进入一个蓝色引导界面:
    选择疑难杂症>启动设置>重启
    再次重启之后,按f4进入安全模式,
    进入安全模式之后,打开设置,搜索设备管理器,
    在显示适配器点击展开,然后选中下面的项目,之后右键,卸载设备
    同时勾选卸载设备的驱动程序,点击卸载
    之后重启系统,此时windows已经恢复正常
2026.3.30 在U盘复制文件到本地的时候显示0x800700EA错误
解决方式:
    将windows系统的时间地区设置中的启用unicode编码取消勾选,
    重新启动就发现可以正常复制了.
2026.7.14 浏览器显示:嗯,您的Internet访问被阻止
    特征是:同一个网页每隔几秒种就会出现加载失败,并显示标题显示的信息,
    然后重新加载,如果重新加载成功,就会正常显示,然后无限循环.
    错误码:ERR_NETWORK_ACCESS_DENIED

    排查网络问题的核心原则:
        0.判断一下网卡适配器是否被禁用
            设置>网络和Internet>高级网络设置>网络适配器:
                看一下是否有需要使用的网络适配器状态显示为开启(此时为禁用状态),
                鼠标左键单击开启按钮后显示为禁用(此时为开启状态)
        1.判断一下网卡驱动程序是否最新,可以使用如下方式更新驱动:
            设备管理器>网路适配器>右键网卡,点击更新驱动程序
            必要时,安装下载驱动精灵,对网卡驱动进行修复和更新
        2.判断一下防火墙对网络的保护
            必要时可以彻底关闭防火墙
            搜索框:高级安全Windows Deferder防火墙
            选择出战规则和入站规则,查看是否有功能被禁用
                右键被禁用的功能选项,点击开启,然后点击窗口右上角的刷新按钮
        3.设备管理器>网路适配器>右键每一个网络适配器,逐个检查以下设置:
            点击属性,在电源管理里面,取消勾选:
                允许计算机关闭此设备以节约电源
            然后点击应用按钮
        4.控制面板>Internet选项>
            安全
                将该区域的安全级别,滑块拉到最低,点击应用
            隐私
                取消勾选:启动弹出窗口阻止程序,点击应用
        5.更换DNS
            设置>网络和Internet>高级网络设置>网络适配器>
                选中每一网络适配器^/v下拉菜单的编辑按钮
                    网络>勾选:Internet协议版本4(TCP/IPv4),点击选中该项
                        然后点击属性>常规
                        点击勾选:使用下面的DNS服务器地址:
                            这里我推荐如下的DNS服务器:
                            阿里云:223.5.5.5
                            谷歌:8.8.8.8
                        设置完成后,点击确定,点击关闭
        6.重置网卡
            以管理员身份打开"命令提示符(CMD)",依次输入以下命令并回车:
            ```cmd
            ipconfig /release
            ipconfig /renew
            ipconfig /flushdns
            netsh winsock reset
            ```
        7.关闭windows防火墙
            使用管理员身份打开powershell,输入如下命令并回车用于关闭防火墙:
            ```powershell
            netsh advfirewall set allprofiles state off
            ```
            需要打开防火墙的时候:
            使用管理员身份打开powershell,输入如下命令并回车用于打开防火墙:
            ```powershell
            netsh advfirewall set allprofiles state on
            ```
        8.最后一步,操作完以上流程
            重启系统,打开浏览器看是否可以解决问题.

    更新这个问题的最新进展:
        1.网络频繁中断:
            以太网光纤传输有问题,导致网络频繁中断,换用无线网络,问题解决.
        2.出现错误码:
            排除了电脑设置的问题,怀疑运营商/公司单位网络限制访问境外网站.
            排查思路:
                换用手机移动网络给电脑开热点看是否可以正确连接目标网址.
                如果可以连通,证明这不是电脑设置的问题,单纯是网络限制问题.
